第 1 步 · 配置电脑

DSH 授权入口

复制本机 DSH Web 启动时显示的带 token 授权链接。它只留在本进程内存中；重启后需要重新输入。

更改入口或端口前请先停止传输，以免中断已有手机连接。

仅接受 127.0.0.1 或 [::1] 的 HTTP(S) 地址和 token 参数。

第 2 步 · 配对手机

短期配对二维码

在独立 iroh 手机 App 中扫码。二维码含一次性秘密，请勿截图、转发或放进日志。

传输就绪后，点击生成二维码。

隐藏或关闭此页面会撤回本页二维码。已复制的内容可能在原到期前仍有效。

第 3 步 · 管理连接

已配对的传输端点

撤销会移除该 iroh 端点并断开其传输连接；不会替代 DSH Mobile 内的设备令牌撤销。

    启动后刷新，可查看已配对端点。
