# Android baseline attribution

The Android WebView shell under this directory is imported from the
`saya-ch/dsh-mobile` project to preserve its tested device-list, pairing,
WebView, and accessibility experience while the iroh transport is developed.

That imported baseline remains covered by the Apache-2.0 license in
`apps/mobile/LICENSE`. Transport-specific code added in this repository is
covered by the repository license unless a file states otherwise.
